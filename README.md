## Files

- `index.html`: page markup
- `styles.css`: styles
- `script.js`: gallery lightbox, copy-email button, scroll reveal
- `images/`: photos

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Publish with GitHub Pages

In the repo go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick the branch and `/ (root)`, and save.
